# Rock surface

`rock_albedo.png`, `rock_normal-gl.png`, `rock_ao.png`, and
`rock_metallic-roughness.png` are one square metre of weathered grey-brown
stone, generated by `rock.py` beside them from periodic noise so every map
tiles: mottled mineral grain, sparse weathering pits, faint bedding bands,
speckle, and warm and cool colour drifts, with the normal and occlusion maps
derived from the same height field. There is deliberately no crack network:
cellular cracks on a rounded body read as a turtle shell. The rocks in
`client/src/map/rocks.rs` project it along each facet's dominant axis and
tint it per variant, with lichen in the vertex colours.

Regenerate with `python3 client/assets/textures/rocks/rock.py` (numpy and
Pillow).
